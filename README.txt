CodeLearn — نسخه نمایشی سایت آموزش برنامه‌نویسی و هوش مصنوعی

اجرا:
1) فایل ZIP را استخراج کنید.
2) فایل index.html را در مرورگر باز کنید.

ویژگی‌ها:
- طراحی فارسی راست‌چین و واکنش‌گرا
- صفحه اصلی، دسته‌بندی‌ها و کارت‌های دوره
- جست‌وجوی دوره و فیلتر دسته‌بندی
- بدون نیاز به نصب یا بک‌اند برای اجرای دمو

توجه:
این نسخه نمایشی است. ثبت‌نام، ورود، خرید واقعی، پرداخت، پنل مدیریت و پخش ویدئوی محافظت‌شده پیاده‌سازی نشده‌اند. آمار، قیمت‌ها و نظرات صرفاً نمونه‌اند.

میزبانی رایگان:
می‌توانید فایل index.html را به‌عنوان یک سایت استاتیک در Cloudflare Pages یا Netlify منتشر کنید. برای فروش واقعی باید بک‌اند/پایگاه داده و سرویس پرداخت به پروژه اضافه شود.
